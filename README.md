# David的公園挑戰

一款 9:16 直式、2D 微像素風格的瀏覽器公園冒險遊戲。玩家可以操控 David 探索大林運動公園，並挑戰六位 NPC 的任務。

## 直接遊玩

Windows 電腦可雙擊 `開始遊戲.bat`，或直接開啟 `public/game/index.html`。

## 操作方式

- 手機：點住 David，往想移動的方向拖曳。
- 電腦：方向鍵或 WASD 移動；Delete、左 Shift、右 Shift 使用技能。
- 空白鍵沒有功能。

## 開發與建置

需求：Node.js 22.13 以上與 pnpm。

```bash
pnpm install
pnpm dev
pnpm build
```

主要遊戲檔案位於 `public/game/`，圖片素材位於 `public/assets/`。
